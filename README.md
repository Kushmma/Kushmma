## 📱 HatBhau

*A Smart Price Comparison Platform for Nepali E-commerce*

<img src="https://img.shields.io/badge/Status-Active-success?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Python-3.12-blue?style=for-the-badge&logo=python"/>
<img src="https://img.shields.io/badge/Flask-REST_API-black?style=for-the-badge&logo=flask"/>

</div>

### ✨ Features

- 🔍 Compare product prices across multiple Nepali e-commerce websites
- 🤖 Automated scraping engines (Shopify JSON, JSON-LD, ajax endpoints)
- ⚡ Flask REST API for fast product search
- 📊 JSON-based API responses
- 🗂️ Admin dashboard with scraper diagnostics
- 🔄 Concurrent-safe scraping with per-domain rate limiting

### 🛠️ Built With

`Python` • `Flask` • `Selenium` • `BeautifulSoup` • `httpx` • `REST API` • `SQLite`
